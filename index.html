¿Qué es HTML?

▶
VIDEO RECOMENDADO · Fazt Curso HTML para Principiantes — qué es, cómo funciona y primeros pasos
↗

HTML (HyperText Markup Language) es un lenguaje de marcado que sirve para estructurar contenido en la web.

👉 No programa lógica — solo organiza lo que ves en pantalla.

📦 HTML organiza

  • ▸ Texto
  • ▸ Imágenes
  • ▸ Botones
  • ▸ Formularios

🤝 Trabaja junto a

  • CSS → diseño visual
  • JS → interactividad
⚙️

¿Cómo se usa HTML?

▶
VIDEO RECOMENDADO · HolaMundo Aprende HTML ahora — para qué sirve y cómo escribir tu primer archivo
↗
01

Crear archivo

Los archivos HTML se guardan con la extensión .html. El nombre index.html es especial: los servidores web lo cargan automáticamente cuando alguien visita tu dominio. Es la "puerta de entrada" de toda web.

index.html
02

Escribir estructura base

Todo documento HTML parte de este esqueleto. <!DOCTYPE html> le dice al navegador que use HTML5. <head> contiene configuración invisible (título, codificación, CSS). <body> contiene todo lo que el usuario verá en pantalla.

<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>Mi web</title>
  </head>
  <body>
    <h1>Hola</h1>
  </body>
</html>
03

Abrir en el navegador

No necesitas un servidor para ver tu trabajo. El navegador puede abrir archivos directamente desde tu computadora. Cada vez que guardes cambios en tu editor, recarga la página para verlos.

Doble clic en el archivo o Arrastrar al navegador o Ctrl + O en el navegador

✅ ¡Ver el resultado en segundos — sin instalar nada!

Etiquetas esenciales

▶
VIDEO RECOMENDADO · DropCoding Etiquetas en HTML — qué son, cómo se usan y ejemplos prácticos
↗
🔹

Títulos

Definen la jerarquía del texto. Van del <h1> (más importante) al <h6> (menos importante). El navegador los muestra en diferentes tamaños automáticamente, y los buscadores como Google los usan para entender de qué trata tu página. 

<h1>Mi Blog de Viajes</h1>
<h2>Mi viaje a Japón</h2>
<h3>Día 1: Tokio</h3>

👉 Usa solo un <h1> por página — es el título principal

🔹

Párrafos

Sirve para mostrar bloques de texto en la página. El navegador agrega automáticamente un espacio arriba y abajo de cada párrafo para separarlo visualmente del resto del contenido. 

<p>Bienvenido a mi sitio web.</p>
<p>Aquí encontrarás tutoriales
   de programación.</p>

💡 Cada <p> inicia en una línea nueva automáticamente

🔹

Enlaces

Crea hipervínculos — texto o imágenes en los que el usuario puede hacer clic para navegar a otra página, sitio web o sección. El atributo href indica a dónde va el enlace. Con target="_blank" se abre en una pestaña nueva sin cerrar la actual. 

<!-- Enlace simple -->
<a href="https://google.com">
  Ir a Google
</a>

<!-- Abre en pestaña nueva -->
<a href="https://youtube.com"
   target="_blank">Ver YouTube</a>

<!-- Enlace a otra sección -->
<a href="#contacto">Ir a Contacto</a>
🔹

Imágenes

Incrusta una imagen en la página. Es una etiqueta vacía (no necesita cierre). src indica la ruta del archivo — puede ser local o una URL. alt es el texto que aparece si la imagen no carga, y lo usan los lectores de pantalla para personas con discapacidad visual. 

<!-- Imagen local -->
<img src="foto.jpg"
     alt="Mi foto de perfil">

<!-- Imagen desde internet -->
<img src="https://picsum.photos/300"
     alt="Imagen aleatoria"
     width="300">

👉 alt es obligatorio — mejora accesibilidad y SEO

🔹

Listas

Agrupan elementos relacionados. <ul> muestra viñetas (•) cuando el orden no importa. <ol> numera automáticamente (1, 2, 3…) cuando el orden sí importa. Cada elemento va dentro de un <li>.

Con puntos • sin orden

<ul>
  <li>Pizza</li>
  <li>Sushi</li>
  <li>Tacos</li>
</ul>

Numerada • con orden

<ol>
  <li>Instalar VS Code</li>
  <li>Crear archivo</li>
  <li>Escribir HTML</li>
</ol>
🔹

Botones

Crea un elemento interactivo en el que el usuario puede hacer clic. Solo muestra el botón — para que haga algo necesita JavaScript. Dentro de formularios, el tipo submit envía los datos automáticamente. 

<!-- Botón básico -->
<button>Haz clic aquí</button>

<!-- Botón que envía formulario -->
<button type="submit">Enviar</button>

<!-- Botón con acción JS -->
<button onclick="alert('¡Hola!')">
  Saludar
</button>
🔹

Formularios

Permite al usuario ingresar y enviar datos. El <form> es el contenedor; dentro van los <input> para campos de texto, email, contraseñas, etc. El atributo type le dice al navegador qué tipo de dato esperar y activa validaciones automáticas. 

<form>
  <!-- Campo de texto -->
  <input type="text"
         placeholder="Tu nombre">

  <!-- Campo de email -->
  <input type="email"
         placeholder="tu@email.com">

  <!-- Campo de contraseña -->
  <input type="password"
         placeholder="Contraseña">

  <button type="submit">Registrar</button>
</form>

💡 type="email" valida automáticamente que el texto tenga @

🔹

Div — Contenedor

Es una caja invisible y genérica que agrupa otros elementos. No tiene significado semántico, pero es esencial para aplicar estilos con CSS y crear layouts. Piénsalo como una "bolsa" donde metes cosas para organizarlas y moverlas juntas. 

<!-- Agrupar una tarjeta de perfil -->
<div class="tarjeta">
  <img src="avatar.jpg" alt="Avatar">
  <h2>Juan García</h2>
  <p>Desarrollador web</p>
</div>

<!-- Layout en columnas -->
<div class="columna">
  <p>Columna izquierda</p>
</div>

💡 Úsalo cuando no haya una etiqueta semántica más apropiada

🔹

Estructura moderna HTML5

HTML5 introdujo etiquetas semánticas que reemplazan al excesivo uso de <div>. Cada una describe claramente su propósito: el navegador, los buscadores y los lectores de pantalla entienden mejor la estructura de la página. Úsalas para organizar tu web como un documento real. 

<header>             <!-- Logo + menú principal -->
  <h1>Mi Web</h1>
  <nav>              <!-- Menú de navegación -->
    <a href="/">Inicio</a>
    <a href="/blog">Blog</a>
  </nav>
</header>

<main>               <!-- Contenido principal -->
  <section>          <!-- Bloque temático -->
    <article>        <!-- Artículo independiente -->
      <h2>Título del post</h2>
      <p>Contenido...</p>
    </article>
  </section>
</main>

<footer>             <!-- Pie: contacto, copyright -->
  <p>© 2025 Mi Web</p>
</footer>
<header> cabecera
<nav> navegación
<main> contenido principal
<section> bloque temático
<article> contenido independiente
<footer> pie de página

🧠 DOM

Cuando el navegador carga tu HTML, lo convierte en un árbol de nodos llamado DOM (Document Object Model). Cada etiqueta se convierte en un nodo que JavaScript puede leer y modificar en tiempo real, sin recargar la página.

<!-- HTML -->
<h1 id="titulo">Hola</h1>

// JS cambia el texto en vivo:
document.getElementById("titulo")
  .textContent = "¡Cambiado!";

Significa usar la etiqueta correcta para cada contenido. Los buscadores como Google leen las etiquetas para entender de qué trata la página. Los lectores de pantalla las usan para ayudar a personas ciegas a navegar.

<!-- ❌ Sin semántica -->
<div>Menú</div>
<div>Artículo principal</div>

<!-- ✅ Con semántica -->
<nav>Menú</nav>
<article>Artículo principal</article>

Mejora: SEO + accesibilidad + mantenibilidad

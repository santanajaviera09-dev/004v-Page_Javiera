La guía definitiva para gestionar tus proyectos, colaborar en equipo y despegar tu carrera como desarrollador.

¿Git o GitHub? No son lo mismo

Git

Es el sistema de control de versiones que vive en tu computadora. Inventado por Linus Torvalds.

  • Funciona localmente.
  • Gestiona el historial de archivos.
  • Es gratuito y de código abierto.

GitHub

Es la plataforma en la nube que aloja tus repositorios de Git y permite colaborar.

  • Funciona en internet (la nube).
  • Red social para programadores.
  • Herramientas de despliegue y CI/CD.

Conceptos Fundamentales

Repositorio (Repo)

La carpeta de tu proyecto que contiene todo el código y el historial de cambios.

Commit

Una "foto" o captura de tu proyecto en un momento exacto. Cada uno tiene un mensaje descriptivo.

Branch (Rama)

Una línea paralela de desarrollo para probar funciones sin romper el código principal.

La "Caja de Herramientas" de Comandos

Comando Descripción
git init Inicia un nuevo repositorio local.
git status Muestra el estado actual de los archivos.
git add . Prepara todos los archivos modificados (Staging Area).
git commit -m "..." Guarda los cambios con un mensaje descriptivo.
git push Sube tus cambios locales al servidor de GitHub.
git pull Descarga y fusiona los cambios remotos en tu PC.

Estados de Git

Working Directory Archivos sin guardar
Staging Area Archivos preparados (add)
Local Repository Cambios confirmados (commit)

Flujo Real de Trabajo

1
Preparación

Crea tu carpeta, inicia con git init y crea tus archivos.

2
Guardado Local
git add .
git commit -m "Agrega login de usuario"
3
Conexión y Subida

Conecta tu repo con GitHub y sube tu código:

git remote add origin URL_DEL_REPO
git push -u origin main

¿Qué es la Algoritmia?

La algoritmia es el estudio y diseño de algoritmos — conjuntos de pasos ordenados y finitos que permiten resolver un problema de forma lógica y eficiente.

◈

Características

  • FINITO Termina en algún momento
  • DEFINIDO Cada paso es claro y preciso
  • ENTRADA Recibe datos como input
  • SALIDA Produce resultados
  • EFICIENTE Usa bien tiempo y memoria

⟨/⟩ EJEMPLO EN PSEUDOCÓDIGO

# Algoritmo simple
leer número
mostrar número * 2

¿Qué significa "en consola"?

Trabajar "en consola" significa ejecutar programas que interactúan con el usuario mediante texto puro, sin ninguna interfaz gráfica. Se usan la entrada y salida estándar del sistema operativo.

→ ENTRADA
⌨️ Teclado del usuario
stdin / input()
← SALIDA
🖥️ Pantalla / terminal
stdout / print()

Algoritmos que organizan datos en orden ascendente o descendente. Cada uno tiene un enfoque, costo y caso de uso ideal.

01
Bubble Sort
Ordenamiento Burbuja
O(n²) Fácil
Compara pares de elementos adyacentes y los intercambia si están en orden incorrecto. Recorre la lista múltiples veces "empujando" el mayor hacia el final.
[5, 3, 2] → [3, 5, 2] → [3, 2, 5] → [2, 3, 5]
✓ Simple de implementar ✗ Lento para listas grandes
02
Selection Sort
Ordenamiento por Selección
O(n²) Fácil
Busca el elemento mínimo en cada iteración y lo coloca al inicio de la sección no ordenada. Menos intercambios que Bubble Sort.
✓ Pocos intercambios ✗ Siempre O(n²)
03
Insertion Sort
Ordenamiento por Inserción
O(n²) O(n) best
Construye la lista ordenada de a poco, tomando cada elemento y ubicándolo en la posición correcta dentro de la sección ya ordenada. Muy eficiente en listas pequeñas o casi ordenadas.
✓ Eficiente si casi ordenado ✗ Lento en listas inversas
04
Merge Sort
Ordenamiento por Mezcla
O(n log n) Estable
Estrategia de divide y conquista: divide la lista en mitades, ordena cada mitad recursivamente y luego las combina (merge). Garantiza O(n log n) en todos los casos.
✓ Siempre O(n log n) ✗ Usa memoria extra
05
Quick Sort
Ordenamiento Rápido
O(n log n) O(n²) worst
Elige un pivote, divide en elementos menores y mayores, y ordena cada subgrupo recursivamente. Uno de los más rápidos en la práctica por su bajo costo en caché.
✓ Muy rápido en promedio ✗ Peor caso O(n²)

⟁ ESTABILIDAD

Un algoritmo es estable si mantiene el orden relativo de elementos con valores iguales después del ordenamiento.

◈ IN-PLACE

Un algoritmo es in-place si no necesita memoria extra significativa — ordena modificando el arreglo original.
